# SmoothSteve Games

This repository hosts the static [SmoothSteve Games](https://smoothsteve.github.io/) website and public player-support pages.

## Structure

- `index.html` — public landing page
- `mad-hatter/privacy/` — The Mad Hatter privacy policy
- `app-ads.txt` — advertising-platform publisher declaration

The site is deployed by GitHub Pages from the `main` branch. Changes should be reviewed in a pull request before they are merged.

## Local preview

Serve the repository with any static web server, then open the local URL in a browser. For example:

```bash
python -m http.server 8000
```

## Security and support

Please follow the private reporting instructions in [`.github/SECURITY.md`](.github/SECURITY.md) for security concerns. Player-support contact details are published on the website.
